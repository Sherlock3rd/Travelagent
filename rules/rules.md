# 项目执行规则

## 基础与角色

继承 Workbencch 的 `rules-bootstrap-spec.md` v1.0；本项目已按 2026-09-24 读取版本同步，原文见 `../spec/rules-bootstrap-spec.md`。

用户默认角色：游戏系统策划。助手默认角色：策划工具开发助手。本项目目标是逐步扩展旅游攻略能力，以本次旅行作为首个实际样本。

## 沟通与变更

- 使用简体中文，所有回复以 `you majesty` 开头。
- 明确简洁执行，不编造目的地、预算、行程、价格或用户偏好。
- 不确定且不同选择会实质改变设计结果时向用户确认。
- 设计、交互意图、命名规则、产出格式变更须先获书面确认。
- 文档、脚手架、目录结构、不影响设计的环境配置可直接执行，并记录 `session/session.md`。
- 用户新增或调整规则时同步本文件；基础规则更新以 Workbencch 最新 bootstrap spec 为准并记录同步时间。

## 执行与复盘

- 开始任务前检索项目 `mistakes/`；无相关项则检索 Workbencch `mistakes/`。
- 先读来源，再实施；区分已确认事实、待确认事项与建议。
- 错误记录包含现象、原因、影响、修复、验证和防呆，同类错误合并归纳。
- 每项需求维护 `session/requirements/` 下的会话；总控会话记录全局状态、验证及提交。
- 新增术语维护 `docs/beagle_glossary.md`，保持 bootstrap 的规定文件名；无关游戏术语保留为非适用说明。

## Git 与服务

- 唯一已确认远程：https://github.com/Sherlock3rd/Travelagent 。保留本地修改，不执行未经授权的 reset、clean 或强制覆盖。
- 仓库当前公开，私密材料统一保存在被忽略的 `private/`，密钥放本机环境变量或部署平台的 Secret。
- 本地运行与 Git 版本管理并行；启动服务不自动拉取、提交或推送。
- 本地服务绑定 `127.0.0.1`；公网部署目标待用户确认，不创建收费资源。
- 校验监听进程与当前目录对应，不能仅凭端口可访问判断服务正确。
- 只允许 `public/` 被 HTTP 访问；规则、会话、Git 元数据和原始材料不发布。
- 旅游时效信息需查询实时来源，记录来源和核验日期；未核验价格/开放时间不能写成确定事实。

## 旅行工作台（2026-09-24 用户确认）

- 单个旅行项目包含地图、每日行程、可勾选物品清单、备注留言、附加攻略五个模块。
- 本次上传的意大利路线图仅参考地图样式，不能当作真实行程来源。
- 实际资料由用户后续补充；空白项目不预填城市、天数、酒店或已确认状态。
- 行程与住宿确认状态分开维护；地图估算不自动改变任何确认状态。
- Supabase 使用用户授权创建的独立 Travelagent 项目；尚未实现业务同步时如实标注。
- 2026-09-24 用户确认地图中文显示及滚轮/移动端缩放；中文地名优先，缺少译名时保留原名，不伪造翻译。缩放与语言更新不得覆盖旅行内容或清单勾选。
- 2026-09-24 用户确认路线加粗、日内安排、目标国聚焦与地图全屏；当日安排独立确认，备选及未知位置不拼接虚假连续路线。增量补充不得覆盖已有清单、留言、攻略或用户编辑。

- 2026-09-24 用户确认具体点位、推荐路线、交通耗时以及地图/点位/事件/行程互跳；推荐方案只作预览，不等同已预订。全程视图必须能发现具体地点，不能仅靠城市点和单日隐藏入口。
