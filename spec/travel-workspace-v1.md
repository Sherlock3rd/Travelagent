# 旅行工作台 v1

## 用户已确认范围（2026-09-24）

同一旅行项目包含五个模块：地图、每日行程表、可勾选的物品准备清单、备注留言板、附加攻略信息。实际旅行资料后续补充。所附意大利路线图仅参考样式，不是本项目的已确认行程。

| 模块 | 首版内容 |
| --- | --- |
| 地图 | OpenStreetMap 底图、缩放/拖动、按天配色、站点标签和方向箭头、全程或单天查看；点击地图定位；自驾/大巴可请求公路估算 |
| 每日行程 | 日期、按顺序的出发/途经/目的地、交通方式、当地出发/到达时间、大致时长、当晚住宿、确认依据和备注；可编辑、排序、删除 |
| 物品准备 | 自建物品、分类、完成勾选、完成数量与进度；删除前确认 |
| 备注留言 | 内容、可选署名、发布时间；当前为本机留言板 |
| 附加攻略 | 标题、分类、内容、来源网址与核验日期；可编辑、删除 |

## 确认状态

- 行程与住宿分别记录“待确认 / 已确认”，不互相推导。
- 新行程默认待确认；只有用户明确选择才标记已确认。
- 编辑既有确认记录时提示重新核实，保存前分别选择新的确认状态。
- “只看已确认”仅针对行程确认状态，不把仅确认住宿的日程混入。

## 地图与参考边界

- 参考图借鉴：地图、每天不同颜色、方向箭头、右侧每日路线、局部放大与估算说明。
- 未提供真实行程前，不添加意大利城市、公里数、旅行天数、酒店或确认标记。
- 地图未定位的站点中断示意连线，不跨过缺失站点生成虚假路段。
- 虚线表示站点顺序；实线表示 OSRM 公路规划，两者都不代表订单确认。
- 公路估算使用普通驾车路径，不能当作大巴、火车或旅行社实际路线，时间不含游览、休息或实时交通。
- 修改站点或交通方式清除旧公路估算；修改备注保留路径。
- 地图服务失败时仍可编辑日程和查看本机数据。

## 保存与云端

- 当前浏览器保存，提供 JSON 导出/导入；校验版本、字段、日期、坐标、链接和重复编号。
- 多标签页更新有提醒及覆盖检查，编辑中的旧表单不能覆盖其他页面的新内容。
- Supabase 免费独立项目已创建；未建业务表、未实现登录、多人留言或跨设备同步。
- Git 只提交应用和文档；浏览器内容不会随 push 上传，真实资料不写入公开仓库。

## 验收

- 空白项目无示例行程。
- 日程、确认筛选、物品勾选、留言、攻略保存与刷新后恢复。
- 地图日路线、颜色、方向、估算在独立测试数据上验证。
- 390×844 竖屏无整页横向溢出；844×390 横屏表单可滚动。
- 使用独立端口验收，不改正式页面旅行内容。
