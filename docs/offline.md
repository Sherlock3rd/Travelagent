# 离线使用

1. 在每台要带出门的设备上联网打开网站主页，等待“离线内容已就绪”。不必逐一打开意大利页签，正文和所有页面会一起下载。
2. 若出现“更新页面”，先保存编辑，再点击启用完整新版。下载失败时旧版仍可继续使用。
3. 出门前在该设备开启飞行模式，再重新打开网站或意大利页签试一次。

可离线使用：旅行主页、意大利总览/每日安排/探索路线/确认清单/来源摘要，以及原工作台已保存的旅行文字。意大利清单的勾选仅存在本机；原工作台仍采用已有云同步机制，离线不把编辑冒充保存成功。

需要网络：外部地图底图、外链照片、官方订票页面、外部导航与云端保存。路线文字已内置，城市地图请另外在地图应用下载。

首次从未联网的设备无法预知网站内容。隐私模式、系统回收空间或手动清除网站数据可能移除缓存，重新联网下载即可；应用升级本身不会清空用户数据。

## 维护

- 发布由 `scripts/build.mjs` 生成全部本地资源与版本依赖清单；支持 GitHub Pages `/Travelagent/` 子目录。
- `sw.js` 只处理清单中的同源 GET。缓存安装完整后才可激活，不缓存 API 或未经许可的本地路径。
- 保留旧缓存给仍打开的标签页使用，不以“修复缓存”为理由删除 localStorage。状态检查逐项确认资源仍在缓存。
- 修改源码后需新版本安装；本机 `public/sw.js` 的开发版本需随修改提升，正式构建自动以提交号/内容指纹区分。
- 技术依据：[MDN Service Worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)、[Cache.addAll](https://developer.mozilla.org/en-US/docs/Web/API/Cache/addAll)。

意大利与原工作台共用地图、每日图文、清单、留言和攻略。13 张参考照片、全部模块及 Natural Earth 地理轮廓随整版缓存保存。离线地理图可缩放、点击点位和路线，但不包含街道细节，不替代离线导航地图。意大利独立本机保存，旧清单迁移且不删除；埃及仍使用原云端工作区。看到更新按钮时先保存编辑，再启用新版本；不清理网站数据。
