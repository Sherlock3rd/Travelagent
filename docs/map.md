# 地图语言与操作

- 中文底图使用 OpenFreeMap 的 OpenMapTiles 矢量数据与 Liberty 样式，MapLibre GL JS 6.11.1 通过官方 Leaflet bridge 0.1.4 接入。保留 Leaflet 行程覆盖层与选点流程。
- 优先顺序：name:zh-Hans → name:zh → name:en → name_en → name；空字符串继续回退。原本为道路编号的文字字段不改成地名。
- 中文名称覆盖由上游数据决定，可能出现繁体译名或原文，不能保证每条道路/商店都存在中文名。中文字符使用设备字体绘制。
- 鼠标滚轮、双击、手机双指缩放和拖动均启用；放大/缩小按钮中文命名，42×42 CSS 像素。主地图和编辑选点地图使用同一配置。
- 浏览器不支持矢量渲染或首次加载超过20秒时回退到原有OSM图片底图，提示中文不可用；行程数据不变。
- 仅向地图服务请求底图瓦片、字体及图标；不上传行程JSON、订单、留言或证件信息。地图服务可以看到请求区域，与原底图的请求方式相同。
- MapLibre 使用同源ES模块与模块worker；服务器提供.mjs的JavaScript MIME类型，并仅为底图域增加connect-src。worker限定同源，未启用unsafe-eval或远程脚本。

- 中文底图浏览器实测显示中文国家与地名；实际滚轮放大可看到更细道路。
- 390×844视口下点击缩放按钮成功，无整页横向溢出；双指选项启用，但工具不支持实际双指手势，真机手势体验尚未验证。

## 国家聚焦、全屏与当日路线（2026-09-24）

- 地图工具栏包含“查看全程”“聚焦目标国家 / 地区”和“全屏展开 / 收起”。旅行信息可设置目标国家，未设置时按钮直接打开配置。
- 国家范围取 Natural Earth 1:110m Admin 0 数据的最大连续陆块包围盒，使用其中文名称；含约177个国家/地区，不是完整行政区目录，离散岛屿/海外属地不保证全部纳入主视图。数据公有领域，来源：[Natural Earth 仓库](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson)；[使用条款](https://www.naturalearthdata.com/about/terms-of-use/)。只用于视角定位，不用于边界测绘。
- 全屏为页面内占满视口，兼容内嵌浏览器；保留选中日期、路线模式与缩放中心。支持 Esc 收起、焦点返回、背景禁用和键盘焦点循环。地图随尺寸变化重新布局，竖屏下日期列表可横向滑动。
- 路线使用高对比颜色、白色描边、5px全程/7px单日线宽与方向箭头；单日隐藏其他日期路线，使用与时间线一致的编号。
- 每日新增独立 activities：名称、位置、时间/建议时段、停留时长、前往方式、确认状态、备注与来源。支持新增、编辑、地图选点、排序和删除；改动主行程不会丢失当日安排。
- 选择日期默认进入“当日安排”（有内容时），可切回“跨城交通”。计划、已确认、备选逐项维护，不继承整天的已确认状态。缺失位置与备选均打断连线；备选显示空心编号，不当作必走路线。
- 未提供分段方案时，当日连线只展示先后顺序；提供方案后按下述分段轨迹展示。未知酒店/码头/接送点保持未定位；具体时间与停留建议不能冒充订单或营业时间。
- 旧 schemaVersion=1 备份保持兼容；缺少 countryCode/activities 自动补空。支持 kind=dayActivities 的增量文件，按记录ID和日期严格匹配，只补空白当日安排；拒绝覆盖已有内容，保留准备清单、留言、攻略及原行程，并沿用多页面并发保护。
- 自动测试覆盖旧备份兼容、增量保留、重复/日期冲突拒绝、未知点/备选不误连、独立确认状态和危险URL拒绝。浏览器验收覆盖桌面国家聚焦、全屏/Esc、日内线路、390×844竖屏、844×390横屏、独立测试站的新增定位/编辑/刷新保留/目标国设置。未进行真机双指手势测试。

## 具体地点、分段交通与关联跳转（2026-09-24）

- 全程 / 国家总览始终叠加具体点位；相近点在低缩放级别合并为可点击的数量圆点，放大后显示名称。侧栏地点索引按坐标聚合，保留同一地点涉及的所有日期、事件和方案。
- 每天支持独立 routePlans 预览：方案包含 stops、legs，点位通过 eventIds 关联当日事件。切换方案仅改变地图显示，不修改确认状态。总览展示每日第一套方案及其他方案中的航段；备选不串成一条必须走完的路线。
- 分段卡片显示起终点、方式、规划时间预算、道路基准里程 / 时间、说明、来源和日期。实际道路为实线，未规划步道 / 海上 / 航段为虚线示意。道路基准不含实时交通、游览、等车或手续，建议预留与基准分别显示。
- 点位→关联事件 / 完整行程 / 当日路线；事件→具体点位 / 分段交通；行程→方案；路段→交通详情 / 事件 / 行程。行程跳转自动打开折叠内容、解除确认筛选并高亮，地图全屏时先恢复页面，焦点落到目标。
- 地图路段也可通过键盘 Enter / Space 打开；地图侧栏和点位弹窗均提供相同功能。方案点位与交通说明可编辑，位置或交通方式变化时清除旧道路；位置变更同时将耗时标记为待重新核对。
- 道路数据校验起终点签名、坐标、数量及端点 600 米容差；景点中心与道路停车处存在偏差时在交通说明中明确注明。地点来源不等同于实地入口核验。
- kind=routePlans 增量导入只填尚无方案的指定日期；拒绝重复日期、不存在的事件 / 起终点、危险链接及失效道路。旧备份自动补空 routePlans，主行程编辑保留新字段，删除事件清理点位关联。
- 真实旅行方案和道路缓存仅在 private/ 与浏览器中；公共应用与测试只包含通用能力及虚构样例。此次导入前后通过可见备份逐项比对，除新增方案和版本号外原数据完全一致。
- 验收：10 项自动测试通过；桌面验证地点→事件→地图、分段详情与键盘开启；390×844 实测无横向溢出、备选分支隔离、全屏点位→事件自动收起并高亮。未声称真机双指手势已验证。

## 地图专注总览（当前交互）

地图侧栏仅保留“每日路线”，各行包含选择日期及“行程 ↗”跳转按钮；方案切换放在地图上方工具栏。取消侧栏地点索引、方案概览、图例及详细行程预览，具体点位仍在地图上显示并提供关联事件跳转。线段弹窗只显示起终点、方式/耗时与行程入口。完整说明、来源及编辑功能位于每日行程的“交通与点位详情”。

地图填满有明确高度的容器，工具栏占用的高度从地图可用空间扣除；每日路线独立滚动，不能再撑高外层造成地图下方露出空白背景。手机全屏时日期列表横向排列。
