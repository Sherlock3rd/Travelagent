# 图文操作攻略

附加攻略以折叠卡片呈现，展开为整行阅读区；目录跳转到章节，底部可返回顶部或收起。旧的纯文字攻略继续可用。

每篇攻略可以包含摘要、章节说明、编号步骤、中英话术、参考图片和逐节来源。话术可复制；图片可打开原图，加载失败保留来源链接与文字说明。编辑已有攻略可修改步骤和话术，图片与来源保留。

`guides` 中新增可选 `summary` 与 `sections`。每节包含 `title/body/steps/phrases/images/links`；备份仍为 schemaVersion 1。验证层统一补充缺省数组，限制长度与数量，正文始终转义为文本，链接限制为 HTTP(S)。嵌入图片限定已核实官方 HTTPS 主机，与本地服务器 CSP 一致；不会接受任意 HTML。

内容补充使用 `kind: "guidesAppend"`、`schemaVersion: 1` 与 `guides` 数组，只追加新编号，遇到已有编号拒绝覆盖。导入确认和保存均检查并发修改。真实旅行内容只保存在浏览器和被忽略的 private 目录。

攻略要求区分政策事实、用户当前状态、待确认项与建议缓冲。政策写核验日期及官方来源；国籍适用范围、旧版费用冲突及不可验证的表单必须明确。网上图片标明来源和用途，环境照不能冒充办理位置图、实际订单或操作截屏。

验证包含旧格式兼容、增量保护、危险链接与图片主机限制、富文本转义；浏览器验证展开、目录、编辑保留、复制后实际粘贴、真实图片加载与手机窄屏阅读。
