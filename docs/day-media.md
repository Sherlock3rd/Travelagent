# 每日路线与景观

每张每日行程卡包含独立的小地图和景观参考图，放在当天详细安排之前。桌面并排，窄屏上下排列；无图片的交通日保留地图，不使用无关景点凑图。

- 小地图读取当天已保存的路线方案，可切换方案、适应路线、聚焦当前方案关联的有图地点，并保持打开大地图时的方案一致。
- 道路轨迹画实线，航段和顺序连线画虚线；未知点位不连线，备选方案不合并。
- 站点编号对应地图下方名称，点击点位可进入关联事件。景观卡片标题也跳到对应安排；图片在页面内放大浏览，不打开新标签。
- 景观注明参考用途、确认/备选状态和来源，不把环境照片当成已分配房间或实时现场。图片不加载时显示重试入口，来源在大图查看器中保留。
- 按视口加载地图，移出视口后释放 WebGL 资源，避免一次创建所有日期的地图。小图用按钮/触摸缩放，滚轮留给页面阅读。

活动保留可选封面 `photo`，新增最多 8 张的 `photos` 补充相册。每张图片对象包含：`url/title/caption/sourceUrl/credit/checkedDate`。旧备份分别按 `null` 和空数组读取，普通事件编辑保留图片。图片主机须与 CSP 白名单一致；文字始终转义。

私有补充格式为 `kind: activityPhotos`、`schemaVersion: 1` 与 `updates`。逐项匹配日期、事件编号和名称，`photo` 仅填空封面；`photos` 仅追加不重复图片，拒绝重复导入、超量或已更名的活动。增量导入不改变其他行程字段及准备状态。

## 图文排版与原位看图

- 每日卡片使用更大的照片网格；首屏最多四张，优先覆盖不同事件，更多照片在相册中浏览。参考状态留在卡片，说明与作者来源放到大图查看器。
- 景观和攻略图片共用原生 dialog，支持关闭、遮罩关闭、上一张/下一张、方向键、Esc、焦点返回；单图隐藏翻页按钮。手机及短横屏保持图片完整显示。
- 当日备注/来源与交通点位细节折叠，所有原文、编辑点位及交通入口保留。无图日期不显示空白图库。
- 地图成功加载后不再显示语言成功说明，缩放说明保留为辅助技术描述。必要的道路/示意图例及失败状态仍保留。
- 本轮私有照片增量回读验证除 photos 和 revision 外全部原数据相同；新增网络照片使用文物官网图库、已关联运营商资料和带作者/许可的公共图库。未下载或提交私人图片清单。
