# 每日路线与景观

每张每日行程卡包含独立的小地图和景观参考图，放在当天详细安排之前。桌面并排，窄屏上下排列；无图片的交通日保留地图，不使用无关景点凑图。

- 小地图读取当天已保存的路线方案，可切换方案、适应路线、聚焦当前方案关联的有图地点，并保持打开大地图时的方案一致。
- 道路轨迹画实线，航段和顺序连线画虚线；未知点位不连线，备选方案不合并。
- 站点编号对应地图下方名称，点击点位可进入关联事件。景观卡片标题也跳到对应安排；图片可打开原图。
- 景观注明参考用途、确认/备选状态和来源，不把环境照片当成已分配房间或实时现场。图片不加载时保留文字和来源。
- 按视口加载地图，移出视口后释放 WebGL 资源，避免一次创建所有日期的地图。小图用按钮/触摸缩放，滚轮留给页面阅读。

活动新增可选 `photo` 对象：`url/title/caption/sourceUrl/credit/checkedDate`。旧备份按 `null` 读取，普通事件编辑保留图片。图片主机须与 CSP 白名单一致；文字始终转义。

私有补充格式为 `kind: activityPhotos`、`schemaVersion: 1` 与 `updates`。逐项匹配日期、事件编号和名称，仅向无图事件追加，拒绝覆盖已有图片或已更名的活动。增量导入不改变其他行程字段及准备状态。
