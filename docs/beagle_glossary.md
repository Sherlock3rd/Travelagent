# 项目术语表

沿用基础规范规定的文件名，集中维护本项目术语。

| 术语 | 定义与使用场景 |
| --- | --- |
| 旅行样本 | 用户此次旅行，作为后续攻略能力建设的首个样本；实际资料待提供。 |
| 本地开发服务 | 从本机工作目录的 public/ 提供页面，用于修改后预览。 |
| Git 远程仓库 | 已确认的 Sherlock3rd/Travelagent，负责版本保存和协作。 |
| public/ | 可被 HTTP 访问的站点文件目录。 |
| private/ | 本机私密原始资料目录，不纳入 Git、不提供 HTTP 访问。 |
| 地块结构、社交类型、友军判定、事件广播 | bootstrap 原始游戏项目术语，在本旅游项目中暂不适用。 |

运行流程见 [工作环境说明](development.md)。
