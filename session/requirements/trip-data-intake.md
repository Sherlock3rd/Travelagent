# 实际旅行资料导入

状态：资料已整理至本机 private/，已通过现有导入流程录入正式工作台并验收。

## 处理口径

- 用户最新明确更正优先于同条消息中粘贴的旧版资料。
- 已出票交通的确认不延伸到同一天的未预订活动；住宿确认单独维护。
- 准备清单不因已有订单自动勾选，打印和装包仍须用户确认完成。
- 入境政策、费用和紧急号码以可核查的官方来源为依据；注明来源年代及适用人群，未核实条件保留待确认。
- 只使用城市级示意点；不冒充机场、酒店、景点的精确定位或真实道路轨迹。
- 可导入 JSON、详细旅行资料和整理脚本均留在被 Git 忽略的 private/，不会由本地 HTTP 服务器发布。

## 验收

- 导入前确认正式页面为空，保留已有代码和公共空白模板。
- 导入数据经现有 validateState 校验，核对日期连续、预订状态和跨日中转计算。
- 页面导入后的显示、确认筛选、刷新持久化、攻略来源和私有路径访问边界检查通过；浏览器无 error/warn。未更改应用代码，本轮无需重复完整代码回归。
