# 每日行程图片与局部地图

- 用户书面要求：每日行程加入地点景观图片及当日路线地图，可使用局部小地图。
- 完成通用事件图片数据、参考图库和各日独立地图；支持切换方案、缩放、聚焦景点、转大图保持方案，以及点位/图片标题到事件跳转。
- 主要景点采用文物部门官网图片，住宿与中转照片采用酒店/机场官方图片。实际旅行关联及图片清单仅在 private 与本机浏览器保存。
- 15 项自动测试通过，覆盖图片增量保护、危险主机、已更名事件与方案隔离；桌面、390×844、缩放、方案切换、图片/点位跳转和编辑保留实测。
- 导出回读：除新增 photo 与 revision 外，原行程、路线、攻略、勾选及留言完全保留。图片资源在浏览器成功加载，移动端无横向溢出。
