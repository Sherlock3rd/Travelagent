# 图文排版与地图总览精简

用户确认：清理常驻说明，丰富景点图片，点击原位看大图；地图不再预览完整行程，仅保留总览及跳转。

实现：更大的四图预览与多图相册，照片说明和来源进入共用大图 dialog；每日备注折叠、交通与点位详情保留编辑；地图侧栏和路线弹窗精简。

验证：16 项自动测试与语法检查通过。实测桌面、390×844、844×390；图像页内打开不改变 URL、不新增标签；翻页、Esc、焦点返回、单张攻略图隐藏翻页、完整行程跳转、交通编辑入口均通过。窄屏无横向溢出，横屏 dialog 无内部高度溢出。
