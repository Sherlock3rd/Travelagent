# 断网后旅行行程不可查看

日期：2026-10-03。

- 现象：断网重新打开 GitHub Pages 网站时页面无法载入，用户感觉所有行程被清空。
- 原因：原页面虽将最近一次云端内容写入 localStorage，但没有 Service Worker 缓存 HTML、JS、CSS；断网冷启动拿不到应用外壳，根本不能读取本机数据。首次加载且没有本机数据时还会网络请求 published-trip.json；失败则显示空白警告。
- 修复：预缓存同源应用文件和已发布的最新行程快照，导航及资源网络优先、离线回退；检测明确离线时立即展示本机行程。云端保存继续只在联网后进行，防止覆盖。
- 验证：模拟安装和断网打开首页、版本化脚本、行程快照；模型校验及云端回读。首次联网加载新版本后再以手机飞行模式实测。
- 防呆：静态快照和云端需同版本；换版本时先完整缓存再清理旧缓存；不要删除 localStorage 或用户保留草稿。外部地图与照片明确不承诺离线可用。
