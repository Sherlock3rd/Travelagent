# 新旅行误用另一套界面

日期：2026-10-10。

- 现象：用户要求在已有旅行工具中增加意大利，却得到不同五页签、纯文字路线，缺少地图与相册，切换行为不一致。
- 原因：把“增加旅行”错误理解为另做专题页；仅验证新增页面自身功能，没有把 rules/rules.md 已确认的五模块、地图和图文交互作为验收基线。
- 影响：用户熟悉的地图、日程跳转、图片查看和备注能力在新旅行中缺失。
- 修复：意大利复用 trip.html 的工作台 DOM 与 app.js/styles.css；旅行数据及存储由 trip-context 隔离。补充实际点位、13 张有作者/许可/来源的参考照片、每日小地图和独立备选路线；兼容旧版 hash 与旧勾选。
- 验证：原版五模块、地图全屏/侧栏、地图→日程→地图、照片大图与翻页；桌面/手机竖横屏；停止应用源后重新打开及未访问照片；独立保存不覆盖埃及。
- 防呆：新增旅行以已有产品功能为默认继承范围，不自行改成新排版。验收必须对照原旅行做真实交互比较，不能只以无报错和文本数量作为完成依据。跳到整日卡片需对齐顶部，不能把很长的卡片居中而隐藏标题和图文。
